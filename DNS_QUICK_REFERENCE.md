## 🛠️ Add Domain to Vercel (3 Methods)

### **Method 1: Vercel Dashboard (Easiest)**
1. Go to: https://vercel.com/dashboard
2. Click **nextjs_space** project
3. Click **Settings** tab
4. Click **Domains** in left sidebar
5. Type: `mindfulchampion.com`
6. Click **Add**
7. Select **"Use External Nameservers"**
8. Wait **5-10 minutes**
9. Click **"Verify DNS"**

### **Method 2: Vercel CLI (Most Reliable)**
```bash
cd /home/ubuntu/mindful_champion/nextjs_space
npx vercel domains add mindfulchampion.com --token 7hAqySfpVwVrqHRk0vIZKDUJ
npx vercel domains add www.mindfulchampion.com --token 7hAqySfpVwVrqHRk0vIZKDUJ
```

### **Method 3: Contact Vercel Support**
If stuck, email: support@vercel.com
